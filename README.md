# Job Market Analysis Using MapReduce and Apache Spark

## Project Overview
This project analyzes a job market dataset using Big Data processing techniques. The goal is to identify salary patterns across occupations, experience levels, education levels, and geographic locations.

## Objective
The objective of this project is to understand the key factors that influence salary and job market distribution using both MapReduce logic and Apache Spark.

## Dataset
The dataset was obtained from Kaggle and contains job market information such as salaries, occupations, experience levels, education levels, and countries.

Dataset link: https://www.kaggle.com/datasets/kundanbedmutha/job-market-dataset-global

## Tools and Technologies
- Python
- MapReduce
- Apache Spark
- PySpark
- pandas
- Matplotlib
- Seaborn

## Methodology
- Loaded and explored the job market dataset
- Implemented MapReduce logic to calculate average salary by occupation
- Used key-value pair processing and aggregation
- Built an Apache Spark pipeline for scalable data processing
- Applied filtering, column selection, feature engineering, sorting, and aggregations
- Analyzed salary patterns by occupation, experience level, education level, and country
- Prepared the processed data for possible future machine learning tasks

## Key Analysis
The project focused on:
- Average salary by occupation
- Salary differences by experience level
- Salary patterns by education level
- Job distribution across countries
- Highest-paying roles and market trends

## Key Findings
- Technical roles such as AI Engineer, Cloud Engineer, and Data Scientist ranked among the highest-paying jobs.
- Senior experience levels were associated with higher salaries.
- Advanced degrees such as Master’s and PhD were linked to higher salaries, especially for senior roles.
- Job opportunities were not evenly distributed across countries.
- The dataset showed a bias toward medium and high-paying jobs.

## Files

## Conclusion
This project demonstrates how MapReduce and Apache Spark can be used to process and analyze job market data efficiently. The analysis shows that salary is influenced by occupation, experience, education, and geographic location.
